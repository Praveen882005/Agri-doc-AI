🌱 Agri Doctor

Agri Doctor is an AI-powered web application designed to help farmers and agriculture enthusiasts identify plant diseases, get crop recommendations, check market prices, find nearby fertilizer shops, and interact with an intelligent agricultural chatbot.

The project uses modern web technologies and Artificial Intelligence to provide smart farming assistance through a simple and user-friendly interface.

🚀 Features
🌿 Plant Disease Detection

Upload plant images to identify diseases
Get disease name, confidence level, description, and treatment steps
🌾 Crop Recommendation System

Location-based crop suggestions
Uses state and district selection
📊 Market Price Analysis

View approximate local crop prices
Interactive charts for easy understanding
🗺️ Find Nearby Fertilizer Shops

Map-based location search
Uses geolocation and OpenStreetMap
💬 AI Chatbot (Agri Assistant)

Helps answer farming-related questions
Supports multiple Indian languages
